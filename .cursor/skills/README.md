# SEO skills

The `seo-*` skills in this folder come from [claude-seo](https://github.com/AgriciDaniel/claude-seo) by AgriciDaniel (MIT license, each skill folder keeps its LICENSE.txt).

Installed subset, picked for a personal content/GEO site:

- `seo-technical`: technical SEO audit (crawlability, indexability, Core Web Vitals, structured data)
- `seo-schema`: detect, validate, and generate Schema.org JSON-LD
- `seo-geo`: Generative Engine Optimization for AI Overviews, ChatGPT search, Perplexity
- `seo-content`: content quality and E-E-A-T analysis, AI citation readiness
- `seo-content-brief`: competitive content briefs with per-section outlines

Skipped from upstream: full-site audit orchestrator, e-commerce, local business, maps, backlinks, programmatic SEO, image generation, and everything under extensions/ (paid or irrelevant APIs). The DataForSEO sections inside the installed skills are optional; they work without it.
